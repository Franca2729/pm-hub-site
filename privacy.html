PM Hub プライバシーポリシー

最終更新日: 2026年11月19日

対象

PM Hub は開発者本人だけが使う個人用ツールです。他の人のデータは扱いません。

Google のデータの使い方

  • Gmail の読み取り権限(https://www.googleapis.com/auth/gmail.readonly)だけを使います。
  • 受信トレイの直近のスレッドについて、差出人名・件名・Gmail が作る短い抜粋・日時を読み、返信が必要そうなものを一覧にします。
  • メールの送信・削除・ラベルの変更は行いません。

保存と共有

  • 判定結果(差出人名・件名・要約・日時)と認証トークンは、利用者本人のパソコンの中にだけ保存します。
  • 返信が必要かどうかの判定のために、差出人名・件名・抜粋を Anthropic 社の Claude に送ります。それ以外の第三者には提供しません。
  • 広告や、AIモデルの学習を目的とした利用はしません。

Google API サービスのユーザーデータに関するポリシー

PM Hub が Google API から受け取った情報の使用と他のアプリへの転送は、Google API Services User Data Policy(限定使用の要件を含む)に従います。

削除

PM Hub の「接続を解除」で保存したトークンを削除できます。また、Google アカウントの設定からいつでもアクセス権を取り消せます。

Privacy Policy (English)

PM Hub is a personal tool used only by its developer. It uses the read-only Gmail scope to read the sender name, subject, snippet and date of recent inbox threads in order to list emails that may need a reply. It never sends, deletes or modifies email. Results and tokens are stored only on the user's own computer. Sender name, subject and snippet are sent to Anthropic's Claude solely to decide whether a reply is needed; no data is shared with any other third party, used for advertising, or used to train AI models. PM Hub's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from your Google Account settings.
